About the game

REANIMATOR is a 3D side-view metroidvania. Wake in a sealed cryo station, work through six connected sectors, and break the reactor core before the meltdown.

  • Explore. Locked doors, hidden walls and ability gates. Thruster Boots, Blast Core, Scan Lens and Thermal Plating open new routes. Energy Tanks raise your health.
  • Fight. Six weapons, a dash with brief invulnerability, a counter, and the three-phase Core Warden.
  • Look back. Press V for Classic View, a 320x200 dithered look that nods to 1996 shooters. The Physics lab replays the recorded movement tests that the run and jump feel was tuned against.

    How the test works

    1. Recorded. The original DOS Abuse 1.05 executable ran each scripted input in an emulator while a harness logged 11 state fields every tick.
    2. Compared. motion.ts starts from the first logged row only, replays the same inputs, and must match every field exactly (tolerance 0, fixed before the first run).
    3. Held out. One scenario was kept aside and never used for tuning.

    15 Hz is a design value. Scope: movement physics only. All art in this game is original.
