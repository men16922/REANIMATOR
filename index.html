How it was revived

Only the player's core 2D movement physics were reconstructed from the 1996 DOS shareware Abuse (v1.05). The Full 3D Side-View Metroidvania game layer (interconnected rooms, locked doors, upgrades, save stations, sector minimap), rigged character models, weapons, bosses, levels, lighting rules, and audio are all original new-design works.

  • Verified DOS Restoration (src/engine/motion.ts): Analyzed ABUSE.EXE (DOS/4GW LE -> ELF) with REA + Ghidra along cop_mover 0x14760 → mover 0x3a1d8 → 0x38704 → try_move 0x37e82 → 0x558e5. Compared field by field with zero tolerance in the Restoration Lab at the 15 Hz design tick (the original tick rate was not measured; zero original DOS art/audio/map bytes ship).
  • New-Design 60 Hz Full 3D Side-View Simulation (src/engine/motion3d.ts, src/game3d/): Side-view run, jump and double jump (Thruster Boots), drop-through grates, Jet-Dash i-frames, 360° mouse aim, 4-weapon arsenal, color-coded lock doors, save stations, E-Tanks, boss shockwaves, and strict R3.3 visual-only headlamp isolation.
  • Rigged Meshy 3D Layer with Split-Body IK (src/render3d/): Rigged Meshy .glb bipeds (operative with hand-socketed pulse-rifle, warden, bio-stalker) animated by Three.js AnimationMixer. Split-Body IK keeps legs on the run/jump clip while the torso and arms aim at the mouse.

    Restoration Lab — 1996 vs 2026

    Same scenario, same start state, same inputs. Every tick, 11 fields, zero tolerance.

    How this is verified

    1. Recorded. The original DOS Abuse 1.05 executable ran each scripted input in an emulator while a harness logged 11 state fields every tick.
    2. Compared. motion.ts starts from the first logged row only, replays the same inputs, and must match every field exactly (tolerance 0, fixed before the first run).
    3. Held out. M05 was sealed. It is judged once per engine revision and never used for tuning.

    15 Hz is a design value. The original tick rate was not measured. Scope: movement physics only. Sprites here are new pixel art; no original art or data ships.
