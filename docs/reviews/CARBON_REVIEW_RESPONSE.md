## 그대로 채택하지 않은 제안

**새 괴물 행동과 즉사 규칙:** 단일 조명 기능에 경계 상태·즉사·괴물 이동을 더하면 설명과 검증이 다시 커진다. 화살 자원의 기회비용 하나로 바꿨다. 재미는 아직 미검증이다.

**자체 Classic 엔진을 1-step 정답 오라클로 사용:** 구현 공유를 독립 원본 검증으로 오해하게 한다. 분기 후 독립 원본 동등성을 주장하지 않고 요구사항 기반 회귀 검증으로 한정했다. 별도의 C 오라클은 이번 필수 범위에서 제외했다.

**REA 블라인드 추출:** 이미 원본 관련 정보를 읽은 상태에서 진정한 블라인드로 주장하면 부정확하다. 현재는 공개 소스 기반 분석의 근거와 한계를 기록한다. 미래의 격리 실험은 별도 프로토콜이 필요하다.

**모든 자유 플레이를 60–90초로 확정:** 시연 시간과 실제 게임 길이는 다르다. 90초 안내 시나리오를 명시하고 자유 플레이 3–5분은 검증할 가설로 남겼다.

**제출 3시간 예약 확정:** 사용자의 실제 일정을 확보하지 않았다. 필요 시간 추정으로만 표시했다.

## 남은 판단

- 사용자에게 의미 있는 ‘내 버전’이 이 규모의 턴제 변형인지 확인이 필요하다. 대형 ARPG를 그대로 기대하면 목표가 다르다.
- 화살 정보 교환이 재미있는지는 플레이로 확인해야 한다.
- 원본 배포본·REA provider·Kiro 실제 사용은 구현 단계에서 확인한다.
- 개선본에 대한 두 번째 Carbon 리뷰는 실행하지 않았다.
