# Playtest observation form (G5)

One sheet per player. The observer does not explain controls before the first input. Small samples do not prove demand.

| Field | Record |
|---|---|
| Player id / date / device | |
| Build (`dist` hash or app revision) | |
| Seconds until first deliberate move | |
| Seconds until first jump / first shot / first light toggle | |
| Understood without help (move, jump, aim, fire, light, goal) | |
| Where they got stuck (time, place, what they tried) | |
| Did they understand the light costs battery? (ask after play) | |
| Result (escaped / died / quit) and run time | |
| Retry? Why / why not (their words) | |
| Volume / flashing / readability problems | |
| Visited "How it was revived" or "Restoration Lab"? What did they think it showed? | |

After three sheets: list the top problems, fixes made, and a re-check on the same build condition.
