## 출품에 직접 영향을 주는 조건

| 항목 | 확인 내용 | 계획 반영 |
|---|---|---|
| 신규성 | 10/30 이후 새 프로젝트. 기존 코드·작업을 포함하면 공개 | 새 REANIMATOR의 신규 기여와 기존 자산을 분리 |
| Kiro | 실제 앱 개발에 사용. 불충분한 사용은 심사상 실격 가능 | 명세·구현·수정의 실사용 기록 |
| 제출물 | 작동 URL, 공개 OSS GitHub, 루트 `.kiro`, 설명, 공개 YouTube 데모 | 별도 제출 체크 |
| 시연 | 3분 미만 권장, 이후 시청 의무 없음 | 2분 40초 목표 |
| 평가 | 5개 기준 각 20%, 공식 규정은 항목당 10점 | 연결 도구의 judging_scale=5와 충돌. 공식 규정을 우선 |
| 마감 | 2026-12-04 22:00 UTC | 12/05 07:00 KST |
| 심사 종료 | 2027-01-29 21:00 UTC | 01/30 06:00 KST까지 무료 접근 |
| 결과 발표 | 2027-02-03 전후 | 발표까지 제출 자료 동결. 일정 재확인 |
| 중복 수상 | Overall 또는 Category 1개, Bonus 추가 가능 | Resurrection+Best Demo 전략 |
| Startup | 창업자 확인, LinkedIn, startup website | 자격 미확인. 자동 지원 대상으로 두지 않음 |

국가·연령·고용관계 등 개인 자격 전체는 이 세션에서 확인하지 않았다. 대한민국과 북한을 혼동하지 않는다. 신규 폴더나 재작성만으로 기존 프로젝트의 적격성을 보장하지 않는다.

## 2025 참고
